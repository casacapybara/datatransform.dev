Find records and export a table
  1. Load JSON or JSON Lines, then choose the collection containing your records.
  2. Search across records or add conditions for individual fields. Select Find records.
  3. Include and arrange the columns you need. Choose an output format and prepare the export.
Use Inspect beside a preview row to see its original structure. JSON exports can preserve matching original records, or use the selected flat table columns. Other formats export a table. Arrays remain in one cell and are never expanded into extra rows.
Parquet export preserves booleans and exact numbers where supported. Text stays text. Exact decimals allow up to 38 digits; larger values need text export. Use the file converter to review and change Parquet column types.
Privacy and limits
Chosen files, documents, queries, schemas and results stay in browser memory. Nothing is uploaded, included in URLs, or saved in browser storage. Clear all data cancels processing and removes tool data. Only the shared theme preference is saved. Copy and download act only when selected. Settings files are exported only when you choose to save them.
JSON and JSON Lines input allow 32 MiB, 250,000 array items, 2 million values and 100 nesting levels. Tables allow 100 columns and 2 million cells. Table previews show 100 rows. Formatted previews show 30,000 characters; downloads include complete results. Operations have a 120-second deadline and can be cancelled. Browser memory can impose a lower practical limit. UTF-8 files and modern browsers with workers are required. Use the hosted site or a local web server.
JSON numbers retain their exact digits. Duplicate object keys are rejected. Library notices: Parquet, JSONPath and schema libraries and SheetJS.
