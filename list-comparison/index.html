Applies to both lists without editing your pasted text. Steps run in this order: remove prefix, remove suffix, replace text, collapse whitespace, normalize Unicode, then trim if selected above. Prefix, suffix and replacement matches are literal and case-sensitive.

Leave blank to remove the found text.

A prefix or suffix is removed once, only at that end of the item. Replace changes every non-overlapping occurrence and treats $ and backslashes literally. Unicode normalization matches composed and decomposed forms such as é; it preserves accents. Changes can merge previously distinct items.

Compare two lists
Paste one list on each side, then choose shared items, items only on the left, items only on the right, a merged distinct list, combined differences, frequency counts, or the full report. Results update automatically. Name the lists to make the exported report easier to read.
For example, compare a left list containing Apple and Pear with a right list containing Pear and Plum. Pear is shared, Apple appears only on the left, and Plum appears only on the right.
Matching ignores case and surrounding whitespace by default. Turn off either option for an exact comparison of that aspect. Trimming also changes displayed values. Optional cleanup transforms both comparison keys and output values while preserving the pasted source. Clear a prefix or suffix, or disable a cleanup checkbox, to restore those source values in the output. Sorting uses your browser’s locale with natural numeric order, so item2 comes before item10. Turn sorting off to retain source order.


Privacy and limits
Lists, names and reports remain in memory. The tool does not upload them, store them or put them in URLs. Copy writes to the clipboard only when selected. Export saves a UTF-8 text file. Clear lists removes both inputs and the report; names and options remain. Reloading clears tool data. Only the shared theme preference is saved. See privacy and analytics.
Each list allows 1,000,000 UTF-16 code units and 20,000 lines, including blank lines. Names allow 100 code units. Cleanup fields allow 1,000 code units each, and transformed data allows 1,000,000 per list. Reports allow 10,000,000 code units; the preview shows the first 30,000. Copy and export include the complete report. Large comparisons may briefly pause the page.
LF, CRLF and CR line endings are supported. With blank lines included, an empty input has no items, but a trailing line break adds an empty item. Whitespace-only lines count as blank only when trimming is enabled. Matching uses lowercase text without accent removal. Unicode NFC normalization is optional. Frequency counts use the same matching and cleanup rules, independent of the deduplication checkbox. With sorting off, the merged list and frequency rows follow first appearance on the left, then new items from the right; combined differences lists left-only items before right-only items. Items-only output has no headings or counts and is available for each list view. An empty result exports an empty file, while an empty item exports a line break. CSV fields and fuzzy matches are not supported. Modern JavaScript and Blob URLs are required. Clipboard access may require HTTPS and permission; export remains available if copying fails.
