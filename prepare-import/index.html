    About value conversions

    Text conversions trim surrounding whitespace. Dates use the explicit order selected and output YYYY-MM-DD, without time zones. Numbers use the selected decimal and thousands separators, preserve all decimal digits and expand exponents. They remove leading zeroes: keep IDs as original text. Accounting parentheses represent negative numbers; currency symbols are not accepted. Blank cells are kept unless a default is set. Failed conversions remain visible in the preview and block import-file export.

    Prepare for your destination
    Load source data and the destination system’s CSV or TSV template. Header-only templates work. Names and column order are preserved exactly; blank, duplicate or overlong template names must be corrected. Sample template rows do not supply defaults or validation rules.
    Choose each source field, add fallback defaults and mark the fields your destination requires. All source rows are kept, and extra source columns are left out of the output. Changing either input resets mappings. Changing any mapping clears the previous result. Every preview starts from the loaded source.
    Resolve every missing required value and failed conversion before exporting the import file. You can download the issue report while the import file is blocked. Checks cover only the rules selected here; your destination may have additional constraints.
    Privacy and limits
    Files, templates, mappings and results stay in browser memory. They are not uploaded, stored or added to URLs. Clear all data cancels processing and clears both inputs and settings. Clipboard and downloads act only when selected. Only theme preference is stored. See privacy and analytics.
    Each input allows 5 MiB. Tables allow 20,000 data rows, 100 columns, 500,000 cells including headers and 20 million characters. Defaults allow 1,000 characters; template names allow 200. Reports allow 100,000 issues and 20 million characters. Exports allow 20 million characters. Decimal conversions allow 1,000 digits.
    Source files can be UTF-8 CSV, TSV, JSON, JSON Lines or Excel, using the shared converter’s limits. Choose a worksheet or JSON collection when needed. Excel formulas use saved results; use displayed text for formatted dates. Malformed or uneven CSV rows block loading. Source headers are trimmed and made unique with warnings; destination headers are preserved.
    Hosted processing uses a local browser worker with a 20-second deadline per operation. Opening this page directly uses the same engine on the page and can pause with large inputs. Modern browsers with workers, TextEncoder, File.arrayBuffer and Blob URLs are required. Clipboard may need HTTPS or permission. Excel uses the locally bundled Apache 2.0 licensed SheetJS library.
