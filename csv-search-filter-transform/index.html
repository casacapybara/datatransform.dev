How the suite works
Load a CSV file or open “Or paste CSV data” and select Load pasted data. Loading replaces the current dataset and resets filters, value changes, manual rows, sorting and output columns.
Search terms are matched as text, with one term per line. Blank lines and duplicate terms are ignored. “Does not contain” excludes a row if any term occurs in any searched column. Leaving search blank keeps all rows for text constraints. Empty-cell constraints ignore search terms and can require any or all searched columns to match.
Changes run from top to bottom on filtered rows. Find and replace changes every literal occurrence, with an optional case-sensitive match. Clearing changes restores the loaded values. Manual rows are appended afterwards. Duplicate removal keeps the first occurrence, then sorting runs before column arrangement and export. Column selection, order and output names apply to every export format. Renamed columns must be unique and non-empty.
Privacy and limits
Files, pasted text and results remain in memory in this browser. They are not uploaded, saved in browser storage or included in URLs. Copy writes to the clipboard only when selected. Reloading or Reset suite clears the data. Only the site’s theme preference is stored. See privacy and analytics.
Supports comma delimiters, quoted cells, doubled quotes and embedded line breaks. Invalid quoting and uneven row widths are rejected. Blank lines are skipped. Blank and duplicate headers receive unique names. Source record numbers count CSV records, including the header, rather than physical lines.
Limits: 5 MiB UTF-8 input, 20,000 data or output rows, 100 columns, 500,000 cells, 100 distinct search terms, 5 million search comparisons and 20 million output characters. Use up to 100 value changes and one sort rule per loaded column. Find text, replacement text and manual cells each allow up to 10,000 characters. Large work may briefly pause the page. No external libraries or services are used.
