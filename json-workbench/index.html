Work with a JSON document
Validate and load your source before using the tree, query, edit, schema or comparison controls. Editing the source clears previous results until you load it again. JSONPath queries return an array of matches. Query downloads include all matches.
Edits use JSON Pointer paths and JSON values. Preview shows additions, removals and changed values before you apply them. Undo retains up to 20 edits within a 32 million character history budget. Clear all data removes the history.
Structural comparison ignores object key order, compares numbers by exact numeric value, and compares arrays by position. Reports show up to 1,000 changes and 2,000 characters per value.
JSONPath filters and schema validation use JavaScript numeric semantics. They stop with an explanation if a document contains numbers that cannot be converted without changing their decimal value. Structural queries and the explorer’s exact numeric filters remain available. Schema references must be contained in the pasted schema; remote schemas are never fetched. Schema errors show up to 200 locations.
Privacy and limits
Chosen files, documents, queries, schemas and results stay in browser memory. Nothing is uploaded, included in URLs, or saved in browser storage. Clear all data cancels processing and removes tool data. Only the shared theme preference is saved. Copy and download act only when selected. Settings files are exported only when you choose to save them.
JSON and JSON Lines input allow 32 MiB, 250,000 array items, 2 million values and 100 nesting levels. Tables allow 100 columns and 2 million cells. Table previews show 100 rows. Formatted previews show 30,000 characters; downloads include complete results. Operations have a 120-second deadline and can be cancelled. Browser memory can impose a lower practical limit. UTF-8 files and modern browsers with workers are required. Use the hosted site or a local web server.
JSON numbers retain their exact digits. Duplicate object keys are rejected. Library notices: Parquet, JSONPath and schema libraries and SheetJS.
