Compare records, not lines
Export two versions of a table as CSV. Load them, review the column matches, then select an ID or a combination such as customer ID and order ID. Compare tables reports records only in Updated as added, records only in Original as removed, and matched records with different values as changed.
Columns with the same trimmed header match automatically, even if reordered. You can map renamed columns or ignore columns you do not want compared. Unmatched columns are listed explicitly. Blank or duplicate headers receive unique names; check the loading warnings before selecting columns.
For prose or configuration edits, use Text diff. For shared items and list differences, use List comparison.
Privacy and limits
CSV inputs and reports remain in memory. Files are read only when selected. Download saves a report to your device. Clear all data removes inputs and results; reloading clears tool data. Only your theme preference is saved. See privacy and analytics.
Each table allows 5 MiB, 20,000 data rows, 100 columns and 500,000 cells including headers. Column names allow 1,000 characters. Reports have a 20 million character budget. Previews show 50 records per page, with cells shortened after 300 characters; downloads contain complete values. Large comparisons may briefly pause the page.
Comma-separated UTF-8 CSV supports quoted cells, escaped quotes and line breaks inside cells. Empty physical lines are skipped. Header-only tables are allowed. Uneven rows and ambiguous keys must be fixed before comparing. Values remain text: no numeric conversion, fuzzy matching or date interpretation. Record numbers count CSV records including the header, rather than physical lines.
